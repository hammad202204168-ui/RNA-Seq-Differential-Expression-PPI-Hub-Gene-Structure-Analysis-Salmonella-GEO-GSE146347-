# results/

All files are **generated** (`make run`, `make ppi`). Do not edit by hand.

* `figures/` Fig0-Fig16, 600 dpi PNG + vector PDF (Fig14 and Fig16 also SVG). Legends: [`../docs/FIGURES.md`](../docs/FIGURES.md).
* `tables/` differential-expression tables (`de_*.csv`), DEG lists, enrichment, robustness, PPI (`ppi_*.csv`), hub structures (`hub_structures.csv`).
* `structures/` reserved for rendered structure images (see `scripts/render_alphafold_cartoons.pml` / `.cxc`).

All results are exploratory (TPM-based, n = 3 per group).
